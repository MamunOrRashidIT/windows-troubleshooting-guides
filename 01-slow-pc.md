# My computer is so slow — what to check first

1. **Restart properly.** Use Restart, not Shut down — Windows "Fast Startup" means Shut down does not fully refresh the system.
2. **Check disk space.** Open File Explorer → This PC. If the C: drive bar is red (under ~10% free), delete or move large files and empty the Recycle Bin.
3. **See what is using the PC.** Press `Ctrl + Shift + Esc` (Task Manager). Sort by CPU, Memory and Disk — one app at 100% disk is the usual culprit.
4. **Trim startup apps.** In Task Manager → Startup apps, disable what you do not need at sign-in (updaters, chat apps). Do not disable your antivirus.
5. **Install pending Windows updates**, then restart once more.
6. **Still slow?** Run a full antivirus scan, and check disk health — a failing HDD is a common cause on older PCs; an SSD upgrade is the single biggest speed-up for them.
